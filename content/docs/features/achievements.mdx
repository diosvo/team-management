## Purpose

- The club's honours, grouped by year on a timeline.
- **Recorded manually:** only our own matches are stored, so final placement
  can't be computed.
- Only once a league has ended, derived from `end_date` on every read (no
  stored status).
- Cups not tracked as leagues become standalone honours (no league).
- MVP and Top Scorer reference a player.

## Access

<PermissionMatrix resource="achievements" />

- COACH records and edits; only SUPER_ADMIN deletes.
- Captains gain nothing here.

## Flows

<Steps>
  <Step>
    ### View

    - Hero banner, then one row per year (descending), a plain `Grid`.
    - Each row: tagline, honour cards, and a quote from the first honour with a
      description.
    - The founding year closes the list when it has no honour.
    - Empty: "The trophy cabinet awaits its first honor".

  </Step>
  <Step>
    ### Record

    - **Record** opens `UpsertAchievement`.
    - The type sets the default title until the title is edited.
    - League picker: **ended leagues only** (`isPast(end_date)`).
    - Year: locked to the league's `end_date`; standalone honours pick between
      the founding year and today.
    - MVP / Top Scorer require a player.
    - With a league selected, the top 5 scorers from `match_player_stats` show
      as one-click chips ("Name — 18.2 ppg").

  </Step>
  <Step>
    ### Edit / delete

    - Hover icons on each card (hidden below `md`).
    - Delete runs `removeAchievement` with a loading toast.
    - Both revalidate `/achievements`.

  </Step>
</Steps>

## Rules

- **Ended leagues only.** `upsertAchievement` rejects unless
  `isPast(league.end_date)`; the client filter is convenience.
- **One honour per type per league.** Partial unique index
  `achievement_league_type_idx` skips `custom` and standalone rows.
- **Honours outlive references.** `league_id` / `player_id` are
  `ON DELETE SET NULL`; a deleted league leaves a standalone honour.
- **Player only for individual types.** Required for MVP / Top Scorer; `null`
  for team honours.
- **Not team-scoped.** `getAchievements` (`withAuth`) returns every row.
- **No `team_id`.** An `achievement` reaches a team only via its league or
  player.

## Acceptance

<Accordions>
  <Accordion title="An active league is rejected">
    A league with a future end_date fails with "Achievements can only be
    recorded for ended leagues".
  </Accordion>
  <Accordion title="Duplicate placement is rejected">

    - A second champion for the same league fails on the unique index.
    - A second custom honour succeeds.

  </Accordion>
  <Accordion title="Leagues link pre-fills the dialog">

    - `/achievements?record=<league_id>` with `achievements:create` opens the
      dialog with that league selected.
    - Other roles just see the page.

  </Accordion>
</Accordions>

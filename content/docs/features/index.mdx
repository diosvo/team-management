title: Feature Catalog
description: Every page in the app with its route, resource key and spec.
---

- Specs are organized **by page**, mirroring the sidebar (`SIDEBAR_GROUP` in
  `src/app/(protected)/_helpers/utils.ts`).
- Route = resource key with a leading slash.
- The proxy maps the route back to the resource and checks `view` before render.
- Table relations: [Data Model](/docs/overview/data-model).

- **Profile:** from the account menu and Roster rows, not the sidebar.

  `/periodic-testing/add-result`.
- **Dashboard:** covers the PDF API `/api/reports/dashboard`.
- **Reports:** covers the cron, download and Resend webhook routes.

- **Browser:** Desktop Chrome only; responsive checks resize the viewport.
- **Timeout:** 20 s per test; traces kept on retry.
- **Report:** HTML in `playwright/report`.
- **Visual:** `maxDiffPixelRatio: 0.01`, to catch docs CSS bleeding into
  the Chakra app.

## Helpers

- `e2e/setup/helpers.ts`: assertions most pages share.
- `e2e/setup/pom.ts`: `DialogPOM` and `TablePOM`, used on nearly every page.

- **Page:** `testNoErrors`, `testNoLoadingState`, `waitForNavigation`,
  `testUrlPersistence`
- **Filters:** `testSearchWithQueryParams`, `testFilterWithQueryParams`,
  `testCheckboxFilter`, `testCheckboxFilterReset`, `testHighlightedText`
- **Tables:** `testTableHeaders`, `testEmptyState`, `testPaginationNavigation`,
  `testRowClickEdit`, `testStatsCardClick`, `testDeleteWithCheckbox`
- **Dialogs:** `testDialogOpenClose`, `testFormValidationDisabled`,
  `testEnterToSubmit`, `testEscapeToCancel`, `testSuccessToast`
- **Misc:** `testKeyboardNavigation`, `uniqueName(prefix)`

## Patterns

- **Page load.** Title, heading, `testNoErrors`, `testNoLoadingState`.
- **URL state.** Search and filters update the query string and survive a
  reload; assert on `toHaveURL`.
- **CRUD through dialogs.** **+ Add**, row click to edit, checkbox to delete;
  each ends in `testSuccessToast` and a table update.
- **Assert invariants, not data.** A guarded check
  (`if (await el.isVisible()) expect(el).toBeVisible()`) can never fail.
- Assert what always holds: the table renders, a coach never sees create.
- **Unique, cleaned-up data.** `uniqueName()` rows, deleted in `afterEach`;
  parallel runs share one database.
- **Wait for state, not time.** Web-first assertions over `waitForTimeout`.
- Visual specs are the exception: chart animations escape
  `animations: 'disabled'`.

## Running & debugging

<Tabs items={['All', 'One file or test', 'UI & headed', 'Debug', 'Visual']}>
<Tab value="All">

```bash
pnpm e2e                    # auth + setup + admin
pnpm e2e --project=admin    # setup runs automatically
```

Requires `PW_USERNAME` and `PW_PASSWORD` in `.env` for the `setup` project.

</Tab>
<Tab value="One file or test">

```bash
pnpm e2e overview/dashboard.spec.ts
pnpm e2e -g "has correct title"
```

</Tab>
<Tab value="UI & headed">

```bash
pnpm e2e:ui
pnpm e2e --headed
```

</Tab>
<Tab value="Debug">

```bash
pnpm e2e --debug            # Playwright Inspector
```

- `await page.pause()` stops at that line.
- Open a retry trace from `playwright/report`.

</Tab>
<Tab value="Visual">

```bash
pnpm exec playwright test -c playwright.visual.config.ts
pnpm exec playwright test -c playwright.visual.config.ts --update-snapshots
```

</Tab>
</Tabs>

## CI status

<Callout type="warn" title="Not running in CI">

- `.github/workflows/playwright.yaml` runs on PRs to `main`, but `if: false`
  always skips it.
- Upload step reads `playwright-report/`, config writes `playwright/report`.
- Fix both when enabling; until then broken E2E flows don't fail a PR.

</Callout>

title: Containers

- A container runs or stores data on its own.
- UI, server actions, API routes and docs are one Next.js deployable.
- The real split: browser, server, headless Chromium and two data stores.

## API surface

- Server actions handle every user write.
- Route handlers only where an action can't: third parties, binary, cron.

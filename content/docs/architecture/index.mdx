- One **Next.js 16 App Router** app on Vercel that a basketball club uses to
  run its teams.
- Pages are React Server Components; PostgreSQL is reached through Drizzle.
- Every write is a **server action** guarded by `withResource`.
- No public sign-up: an admin or captain provisions accounts.
- Invitees activate through a password-reset email.

## Key decisions

- **One deployable.** UI, actions, API routes and docs in one Next.js app.
- **Actions are the only write path.** Wrapped in `withResource(resource)`;
  the proxy only gates `view`. See
  [Roles & Permissions](/docs/access/roles-permissions).
- **One permission function.** `can(role, resource, action, isCaptain?)` in
  `src/utils/permissions.ts`, shared by proxy, actions and client hook.
- **Serverless-first.** `pg.Pool({ max: 1 })`, Chromium pack fetched at
  runtime, crons under the 60 s limit.
- **Docs in the app.** Fumadocs serves `/docs` and `/docs/vi` from
  `content/docs`.

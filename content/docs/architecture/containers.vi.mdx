- Container là phần tự chạy riêng hoặc tự lưu dữ liệu riêng.
- Giao diện, server action, API route và docs được deploy chung thành một app
  Next.js.
- Thật ra hệ thống chia thành: trình duyệt, server, Chromium headless và hai
  nơi lưu dữ liệu.

## Các API

- Mọi thao tác ghi của người dùng đều đi qua server action.
- Chỉ dùng route handler khi action không làm được: dịch vụ bên ngoài, dữ liệu
  binary, cron.

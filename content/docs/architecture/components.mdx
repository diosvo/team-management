## Conventions

- **Validation.** `src/schemas` Zod drives react-hook-form; actions re-parse.
  `getDefaults()` / `getMaxLength()` (`src/lib/zod.ts`) keep them in sync.
- **Scope from the session.** `team_id` and actor come from the injected
  `user`, never from arguments.
- **Request dedup.** Shared reads use React `cache()`, keyed on primitives.
- **Streaming.** One `<Suspense>` per dashboard section; Recharts, TipTap,
  `pdf-lib` and role-gated dialogs load lazily.

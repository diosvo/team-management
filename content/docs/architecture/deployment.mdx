      required: true,
    },

- Both require `Authorization: Bearer $CRON_SECRET`; Vercel adds it to crons.
- An empty `CRON_SECRET` rejects everything.

## Environment variables

- `env.config.ts` parses `process.env` with Zod; import it as `@env`.
- Every variable has a default: builds never fail, the feature fails at runtime.
- Better Auth reads `BETTER_AUTH_URL` and `BETTER_AUTH_SECRET` directly.

## Known gaps

<Accordions>
  <Accordion title="Production deploys run no tests">
    `production.yaml` sets `run-unit-test: false`; a direct push to `main`
    skips the PR gate.
  </Accordion>
  <Accordion title="E2E is disabled in CI">
    `playwright.yaml` is skipped until CI has an isolated test database.
  </Accordion>
  <Accordion title="Sandbox email sender">
    `EMAIL_FROM` is `Acme <onboarding@resend.dev>` (Resend sandbox), not a
    verified club domain.
  </Accordion>
  <Accordion title="Reports serve a single team">
    The cron renders as one service account; only its team gets scheduled
    reports.
  </Accordion>
  <Accordion title="Misspelled enum asset_catogory">
    `asset_catogory` in `src/drizzle/schema/asset.ts`; renaming needs a
    migration.
  </Accordion>
  <Accordion title="Scaffolded documents resource">
    `documents` is in `RESOURCES` and the sidebar (`disabled: true`) but has
    no route or table.
  </Accordion>
</Accordions>

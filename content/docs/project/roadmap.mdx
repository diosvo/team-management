- Schema items track `TODO.md`; a migration number means shipped.

## Shipped

- **Features:** every page in the [feature catalog](/docs/features):
  - Dashboard (PDF report), Reports, Achievements, Team Rule, Roster, Training.
  - Attendance, Registration, Matches, Periodic Testing, Assets, Emails.
  - Teams, Leagues, Locations, Profile, Sign-in Pages.
- **Platform:**
  - Better Auth (rate-limited credential routes), Vercel Blob, Resend.
  - Puppeteer and `pdf-lib` PDFs.
  - Responsive layout for phones, tablets and laptops.
- **Data model:**
  - `0008` jersey numbers unique per team.
  - `0009` attendance per training session.
  - `0010` asset names unique per team.
  - `0011` `test_result.date` NOT NULL.
  - `0012` `league_team_roster` bound to `league_team`; `league.status`
    derived at read time.
  - `0014` `report_schedule` and `report_history` for scheduled reports.
  - `0015` `user_team` membership history; `user.team_id` stays the current
    team, `match_player_stats.team_id` keeps per-match team context.
  - `0016` `team.is_external` flags opponents.
  - `0017` `rule` table merged into `team.rule_content`.
  - `0018` `match.status` (scheduled, completed, cancelled), scores only on
    completed matches; `match.home_team` / `away_team` restrict team deletion.
- **Docs:** served at `/docs` (Vietnamese at `/docs/vi`), `llms.txt` exports,
  permission matrix generated from `ROLE_CONFIG`, C4 architecture section.

## Not planned

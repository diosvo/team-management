## Non-functional requirements

<Tabs items={['Performance', 'Accessibility', 'Reliability']}>
  <Tab value="Performance">

    Common pages render within 2 s at the team sizes in the
    [constraints](/docs/overview/vision#constraints).

    - **Streaming.** Each page section has its own `Suspense` boundary and
      skeleton; no waiting on every query.
    - **Reads.** Live in `src/db`, wrapped by `withAuth` in `src/actions`;
      never called from components.
    - **Lazy deps.** Charts, rich-text editor and PDF engine
      (`src/lib/puppeteer.ts`) load on demand, not in first-load JS.

  </Tab>
  <Tab value="Accessibility">

    - Keyboard navigation for tables, menus and dialogs (Chakra UI primitives).
    - Dialogs and drawers trap focus and restore it on close.
    - Every action control has a text label or `aria-label`.

  </Tab>
  <Tab value="Reliability">

    - **Responses.** Mutations return a `ResponseFactory` `Response`
      (`success`, `message`, optional `data`), shown as a toast.
    - **No duplicate writes.** Submit buttons disable while pending.
    - **Unique indexes.** `unique_player_per_session`, `team_asset_name`, ...
      catch the rest; `getDbErrorMessage` translates them.
    - **Rate limits.** Better Auth: 3 requests/min per IP on sign-in and
      password reset.

  </Tab>
</Tabs>

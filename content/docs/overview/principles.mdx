- **UX principles (4):** what a reviewer checks against.
- **Technical contracts (3):** the code that makes them true.

## UX principles

- **Role clarity.** `Authorized` hides what the role cannot do; the proxy
  sends the rest to `/forbidden`.
- **Fast search.** Every list filters by `q` and by its categorical columns.
- **Safe destructive actions.** Deletes confirm first and report through a toast.
- **Deep-linkable state.** Filters, search and page live in the URL.

## Authorization is server-side

- **Writes.** `withResource` in every server action is the only check that
  can't be bypassed; the UI just hides controls.
- **Reads.** `withAuth` redirects to `/login` when there is no session.
- **Grants are role + resource, not row.** For own records (profile, leave,
  avatar) the action compares with session `user`; mismatch → `forbidden()`.
- **Never trust payload IDs.** `team_id` comes from the session; a submitted
  `user_id` or `player_id` is checked against it.

Full matrix and rules: [Roles & Permissions](/docs/access/roles-permissions).

## Send the client only what it renders

- Server Components read only the displayed columns, never whole rows.
- `getRoster` returns `RosterUser`: name, email, role, state, jersey number.
- Date of birth, phone and citizen ID stay on the server, except on the
  profile page (own ownership rule).
- The protected layout passes only `session.user` to `SessionProvider`,
  never the session token.

## The URL owns filter state

- `q`, `page` and filters are parsed by `nuqs` (parsers in `src/lib/nuqs.ts`).
- Local state (search box, Advanced Filters drawer draft in
  `src/components/filters/Filters.tsx`) only mirrors the URL.

Two-way contract:

- **Local to URL** on commit: Apply, debounced typing, stat-card click.
- **URL to local** on any external change: card click, back, reset, deep link.

`useSyncedState` (`src/hooks`) owns the resync:

- Adjusts state during render.
- Compares by value, so rebuilt array params don't trigger a false resync.
- Never writes back to the URL.

Guarantees this buys:

- A stat-card click setting `q=''` clears the search box; stale text can't
  return to the URL.
- The drawer draft opens from the URL, diverges while editing, commits on
  Apply, reverts on interact-outside.
- One URL write (back button, deep link) fans out to every mirror at once.

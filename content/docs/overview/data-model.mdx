## Membership over time

- `user_team` keeps one row per stint, so transfers and rejoins keep their history.
- `user.team_id` points at the open stint; `transferMembership` closes the old
  stint and moves the pointer in one transaction.
- `user_current_team` allows one open stint per user; `user_team_stint` allows
  rejoining a team, but not the same stint twice.
- `match_player_stats.team_id` keeps old box scores on the team played for.
- Jersey numbers stay unique per team in the action layer, not the database.

## Deletion behaviour

<TypeTable
  type={{
    'Delete team': {
      type: 'cascade / restrict',
      description: (
        <ul>
          <li>Cascades to users, memberships, assets, test types, sessions.</li>
          <li>Also league junctions, report schedules and history.</li>
          <li>
            Blocked while a match uses it as <code>home_team</code> /{' '}
            <code>away_team</code>.
          </li>
          <li>
            <code>onDelete</code> restrict, also guarded in{' '}
            <code>removeTeam</code>.
          </li>
        </ul>
      ),
      required: true,
    },
    'Delete user': {
      type: 'cascade',
      description: (
        <ul>
          <li>Sessions, accounts, memberships, player / coach.</li>
          <li>From player: attendance, roster entries, stats and results.</li>
        </ul>
      ),
      required: true,
    },
    'Delete league': {
      type: 'cascade',
      description: (
        <ul>
          <li>
            <code>league_team</code>, <code>league_team_roster</code> and the
            league matches.
          </li>
          <li>
            <code>achievement.league_id</code> is set null.
          </li>
        </ul>
      ),
      required: true,
    },
    'Delete training_session': {
      type: 'cascade',
      description:
        'Its attendance rows; rescheduling (date update) cascades into attendance.date.',
      required: true,
    },
    'Delete test_type': {
      type: 'restrict',
      description:
        'Rejected while results exist (onDelete restrict, also guarded in removeTestType).',
      required: true,
    },
    'Delete location or coach': {
      type: 'set null',
      description:
        'Referencing sessions and matches survive with the column cleared.',
      required: true,
    },
    'Delete report_schedule': {
      type: 'set null',
      description: 'Past runs stay in report_history with schedule_id cleared.',
      required: true,
    },
    'Delete an assigned user': {
      type: 'set null',
      description:
        'asset.assigned_to is cleared; the asset stays in inventory.',
      required: true,
    },
  }}
/>
